1. General System Architecture & Requirements
System Capacity: 500+ IP Kameralar (Zero-Crash Architecture).

Technology Stack:

Backend: C# (.NET 8/9), ASP.NET Core Worker Service, FFmpeg.AutoGen / LibVLCSharp.

Frontend: C# WPF, Direct3D / Silk.NET / LibVLCSharp HW Accelerated Grid Rendering.

Databases: PostgreSQL (System Config & ACL), Elasticsearch / Redis (AI Metadata Indexing).

Core Functionalities:

ONVIF Integration: Multi-brand discovery & RTSP stream negotiation.

GPU HW Acceleration & Multi-streaming: Dual Stream (Main 4K/1080p for Archive/Single View, Sub-stream D1/VGA for Grid View). NVIDIA NVDEC (CUVID) / Intel QuickSync / DXVA2 acceleration.

Auto-retention & Retention Policy: Automated cleanup loop for expired archives.

Write-Protection / Immutable Archive: Windows File Security ACL & Read-Only locking (Admin authorization enforcement).

AI Metadata Indexing & Fast Search: Storing structured JSON payloads for objects instead of indexing raw video.

Role-Based Access Control (RBAC): Admin/SuperAdmin control override, Operator, and Viewer role isolation.

Dynamic 5-Second Video Clip Generation: Fast stream-copy extraction (-c copy) on metadata match with automatic hover/popup looping.

3. Module-by-Module Technical Implementation Specifications
STEP 1: Core Domain Models & RBAC Security (VMS.Core)
User & Roles Definition: User, UserRole (SuperAdmin, Admin, Operator, Viewer).

Security & Hashing: SHA256 + Salt / BCrypt Authentication Service (AuthService).

Access Control Manager: Centralized permission checks (AccessControlManager) enforcing:

Only SuperAdmin can delete write-protected/immutable archives.

Only Admin & SuperAdmin can add/edit cameras and system configurations.

Audit Trailing: Append-only event logging (AuditLogger) tracking all admin actions.

STEP 3: Storage Engine & Write-Protection (VMS.StorageEngine)
Immutable Storage Writer:

Windows FileSystem ACL application: Deny Delete permissions for standard users/groups.

File.SetAttributes(ReadOnly) flag enforcement for locked clips.

Auto-Retention Loop:

Background task scanning archive folders based on configured retention policy (e.g., 30 days).

Skipping immutable/protected clips while purging standard expired files.

Fast 5-Second Clip Extractor (VideoClipExtractor):

Pre-roll (2s) and Post-roll (3s) calculation based on detection timestamp.

Native stream-copying via FFmpeg CLI/API (-c copy) without re-encoding for sub-50ms clip generation.

STEP 4: AI Metadata Indexing (VMS.MetadataIndexer)
Metadata Payload Schema: ObjectMetadata (Timestamp, CameraId, ObjectType, Confidence, BoundingBox, VideoChunkLocation).

Indexing Service: High-speed event ingestion into Elasticsearch / Local Index for lightning-fast queries.

STEP 5: WPF Client Frontend (VMS.Frontend.WPF)
Login & Role-Aware UI:

Dynamic UI binding hiding/disabling Admin Controls, Camera Settings, and Delete buttons for non-Admin users.

High-Performance Live Grid:

Multi-view Grid Layout (4x4, 8x8) consuming Sub-streams.

Dynamic switching to Main-stream on single-camera expansion.

AI Search Side-Panel & 5-Second Loop Player:

Sidebar search input ("Red Car", "Person", "Face").

Result list showing high-resolution thumbnails and metadata timestamps.

SelectionChanged handler triggering VideoClipExtractor and displaying the 5-second MP4 in a WPF Popup / MediaElement with continuous looping (MediaEnded).
